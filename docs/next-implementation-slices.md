# Recommended implementation slices

## Slice 1 - Manual ingestion baseline

Complete the included VTT upload workflow, add browser playback for uploaded audio and tighten tenant authorization with policies.

## Slice 2 - Meeting intelligence extraction

Add versioned summaries, decisions, actions, risks and opportunities. Every extracted item must include one or more evidence links to transcript segments.

## Slice 3 - Microsoft Teams connector

Implement OAuth administration, Graph subscriptions, webhook lifecycle renewal, meeting occurrence resolution, recording/transcript download and participant mapping.

## Slice 4 - Governance controls

Add consent records, configurable retention, legal holds, classification labels, access logs, deletion workflows and administrator reports.

## Slice 5 - Additional providers

Implement Google Meet and Zoom adapters using the same normalized provider contract and reconciliation process.
